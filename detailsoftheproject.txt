4.2 Technical Analysis Engine
Purpose
Calculate indicators used in prediction and analysis.
________________________________________
Indicators Used
1. Simple Moving Average (SMA)
Used to identify trend direction.
Formula:
SMA=(P_1+P_2+...+P_n)/n
Where:
	P = Price
	n = Number of periods
________________________________________
2. Exponential Moving Average (EMA)
Gives higher importance to recent prices.
Formula:
EMA_t=(P_t×k)+EMA_(t-1) (1-k)
Where:
k=2/(n+1)
________________________________________
3. Relative Strength Index (RSI)
Measures overbought/oversold conditions.
Formula:
RSI=100-100/(1+RS)
Where:
RS=(Average Gain)/(Average Loss)
________________________________________
4. MACD
Moving Average Convergence Divergence.
Formula:
MACD=EMA_12-EMA_26
Signal Line:
Signal=EMA_9 (MACD)
________________________________________
5. Bollinger Bands
Formula:
Upper=SMA+2σ
Lower=SMA-2σ
________________________________________

or

4.5 Portfolio Analytics Engine
Purpose
Analyze investment portfolio health.
________________________________________
Features
	Diversification analysis
	Risk analysis
	Asset allocation
	Correlation analysis
	Drawdown analysis
	Volatility analysis
________________________________________
Portfolio Return Formula
R_p=∑w_i R_i
Where:
	w = asset weight
	R = asset return
________________________________________
Portfolio Variance
σ_p^2=∑w_i^2 σ_i^2+∑∑w_i w_j Cov(i,j)
________________________________________
Sharpe Ratio
Measures risk-adjusted return.
Sharpe=(R_p-R_f)/σ_p 
Where:
	Rp = portfolio return
	Rf = risk-free rate
	σp = portfolio volatility
________________________________________
Beta
Measures market sensitivity.
β=Cov(R_i,R_m )/Var(R_m ) 
________________________________________
Maximum Drawdown
Measures worst historical decline.
Formula:
MDD=(Peak-Trough)/Peak
________________________________________
Correlation Matrix
Used to identify diversification.
Correlation Formula:
Corr(X,Y)=Cov(X,Y)/(σ_X σ_Y )
________________________________________
4.6 Risk Analytics Engine
Purpose
Quantify portfolio risk.
________________________________________
Value at Risk (VaR)
Measures expected loss.
Formula:
VaR=μ-zσ
Where:
	μ = expected return
	z = confidence level
	σ = standard deviation
________________________________________
Conditional VaR (CVaR)
Expected loss beyond VaR.
Formula:
CVaR=E[Loss|Loss>VaR]
________________________________________
Volatility
Formula:
σ=√((∑(x_i-μ)^2)/N)
________________________________________
Risk Scoring
Example:
Risk Score	Interpretation
0-30	Low Risk
31-60	Medium Risk
61-100	High Risk
